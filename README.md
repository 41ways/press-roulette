# 꾹꾹 룰렛

https://41ways.github.io/press-roulette/

항목마다 공 하나로 시작한다. 위에서 프레스가 내려와 눌린 공은 작은 공 3개로 쪼개지고, 상자가 꽉 차면 펑 터진다. 그때 공이 가장 많은 항목이 당첨.

- 항목 2~8개. 고친 항목은 브라우저에 남고, 돌리면 주소 뒤 `#i=` 에도 남아서 그 주소를 보내면 같은 항목으로 열린다.
- 처음 공 순서는 매번 섞는다. 가운데(프레스 밑)에 놓인 공이 먼저 눌리니까.
- `engine.js` 가 물리, `index.html` 이 화면. 빌드 없음.

## 손볼 때

`engine.js` 의 `CFG` 숫자를 바꾸면 판 길이와 공 개수가 달라진다. 바꾼 뒤엔 헤드리스로 몇 판 돌려 본다.

```
node tools/sim.js 6 3          # 6판, 항목 3개
node tools/sim.js 4 8 BLOCKN=20
```

지금 값으로는 한 판 33~40초, 공 1,400~1,700개쯤에서 터진다.
